# Specs

This directory is the bigpowers planning cockpit.

- `state.yaml` records the current session and handoff.
- `release-plan.yaml` indexes release epics.
- `execution-status.yaml` owns epic and story status.
- `planning-status.yaml` records discover-phase progress.
- `product/` contains scoped product artifacts.
- `epics/` contains implementation capsules.
- `tech-architecture/` contains durable technical analysis.

Project design authority remains under [`docs/design/`](../docs/design/README.md).
